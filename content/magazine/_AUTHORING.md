# 읽을거리(매거진) 작성 가이드

사우나우 `읽을거리` 피드에 들어가는 아티클을 작성·발행하는 규칙입니다.
글 하나 = `content/magazine/<slug>.md` 파일 하나. 렌더러는
[`components/magazine/ArticleBody.tsx`](../../components/magazine/ArticleBody.tsx),
적재는 `pnpm import:articles` (스크립트: `scripts/import-articles.ts`).

---

## 1. 파일 형식

frontmatter + 본문(마크다운). 파일명은 `slug`와 같게(영문 kebab-case).

```markdown
---
title: 물 건너 일본의 사우나 문화, 사우나(サウナ)와 토토노우
summary: 핀란드식과 다른 일본 사우나의 매력 — 냉온교대욕과 "토토노우"
slug: japan-sauna-culture        # 없으면 파일명 사용
thumbnail_url:                   # 선택. Supabase Storage public URL
published_at: 2026-06-30         # 없으면 오늘
is_published: true               # 기본 true. 초안은 false
---

본문 마크다운…
```

| 필드 | 필수 | 설명 |
|------|:---:|------|
| `title` | ✅ | 목록/상세 헤드라인 |
| `summary` | 권장 | 목록·상세 상단 리드. 한 문장, 마침표 없이 담백하게 |
| `slug` | | 영문 kebab-case. URL이 됨(`/feed/<slug>`) |
| `thumbnail_url` | | 없으면 `ArticleThumb`가 slug로 일러스트 매칭 |
| `published_at` | | `YYYY-MM-DD` |
| `is_published` | | `false`면 발행 안 됨(초안) |

---

## 2. 쓸 수 있는 마크다운 (심심하지 않게!)

표준 마크다운 + 아래 확장. **글이 밋밋하면 아래 요소를 적극 섞는다.**

### 제목
- `##` (h2) — 섹션. 앞에 빨강 악센트 바가 자동으로 붙는다.
- `###` (h3) — 소제목.
- 본문에 `#` (h1)은 쓰지 않는다(제목은 frontmatter `title`).

### 강조 · 형광펜
- `**굵게**` — 핵심 단어.
- `==형광펜==` — 브랜드 색 마커. **한 문단에 1~2개**만. 남발 금지.

### 목록
- `1.` 순서 목록 — 절차/순서(마커가 빨강 볼드). 단계 첫 단어는 `**굵게**`.
- `-` 순서 없는 목록 — 병렬 항목.

### 콜아웃 (박스) — `> [!타입] 제목`
블록인용 첫 줄에 타입을 적으면 색 박스가 된다. 제목은 생략 가능.

```markdown
> [!tip] 제목(선택)
> 본문 내용. 다음 줄도 이어서 쓸 수 있어요.
```

| 타입 | 색 | 아이콘 | 언제 |
|------|-----|:---:|------|
| `tip`  | 초록 | 💡 | 실전 꿀팁·추천 |
| `note` | 파랑 | 📌 | 용어 설명·배경지식 |
| `warn` | 빨강 | ⚠️ | 안전·주의·면책 |
| `hot`  | 빨강 | ♨️ | 뜨거움/사우나실 포인트 |
| `cold` | 파랑 | 🧊 | 냉탕/냉수욕 포인트 |

> 안전·건강 관련 면책 문구는 **항상 `> [!warn]`** 로 넣는다.

### 구분선 · 인용 · 이미지 · 링크
- `---` — 짧은 가운데 구분선. 큰 흐름 전환에만.
- `> 일반 인용` — 타입 없는 블록인용(회색).
- `![대체텍스트](url)` — 이미지. alt를 쓰면 가운데 캡션으로 노출.
- 인스타 게시물 URL을 **한 줄 단독**으로 적으면 자동 임베드.

---

## 3. 문체 · 톤

- **독자**: 사우나/목욕탕을 즐기려는 한국 일반 이용자. 초심자도 이해되게.
- **어투**: 존댓말(`~습니다/~해요`), 담백하고 친근하게. 과장·낚시 금지.
- **길이**: 400~800자 안팎. 스크롤 3~5화면. 섹션 2~4개.
- **구조**: ①리드(왜 읽나) → ②`##` 섹션들 → ③마무리/주의.
- **사실**: 영업시간·가격 등 확정 정보를 지어내지 않는다(모르면 안 씀).
- **의학·안전**: 효능을 단정하지 말고 "알려져 있습니다" 수준. 위험은 `[!warn]`.
- **일러스트 용어**: 목욕탕·찜질방·온천·노천·세신 등은
  [`components/illustrations/`](../../components/illustrations/)의 통일된 의미로 쓴다.

---

## 4. 발행

```bash
pnpm import:articles -- --dry   # 파싱 확인(DB 미적재)
pnpm import:articles            # slug 기준 upsert 발행
```

새 글은 `is_published: false`로 초안 → 검토 후 `true`로 바꿔 다시 import.
